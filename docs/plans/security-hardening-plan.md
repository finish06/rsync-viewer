## Decisions made while planning (flag if you disagree)

1. **Legacy keys keep working** via a scan restricted to `key_prefix == ""` rather than being disabled — the prefix cannot be reconstructed from a bcrypt hash, and forcing rotation on a homelab install is disproportionate. Rotation is nudged via a log warning.
2. **Rate limiting is per-IP for everyone**, including authenticated API-key traffic. Per-key quotas can return later keyed on the *matched* key id (post-auth), which does not have the bypass problem.
3. **`FORWARDED_ALLOW_IPS` defaults to `127.0.0.1`**, which means an unconfigured proxied deployment will see all clients as the proxy IP (shared rate bucket, wrong log IPs) — safe failure mode, documented in README.
4. **Unverified OIDC email refuses login** rather than creating a separate account, to avoid squatting an existing user's address.
5. **Webhook list/edit become operator-only** rather than redacted-for-viewers; the settings page hosting them is already operator-only, so viewers lose nothing they could reach through the UI.
6. **`ApiKeyDep` is deprecated, not removed** — the test fixture overrides it; removal is a Phase 3 cleanup.
